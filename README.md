# Diagnóstico de marca · Kevin Ribeiro

Formulário de 60 perguntas para coletar o que eu preciso saber para criar a marca, o site e o portfólio de um cliente.
Site estático (GitHub Pages). As respostas vão para um Google Apps Script que grava numa planilha privada.

Fonte das perguntas e do coletor: repositório privado `kev_coder`, pasta `materiais/diagnostico-de-marca/`.
Não edite `perguntas.js` à mão: ele é gerado por `build.py` lá.
